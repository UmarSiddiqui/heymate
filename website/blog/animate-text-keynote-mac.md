# How to animate text in Keynote on Mac

Make a Keynote title fly in. Find Animate, add a Build In effect, and check timing in Build Order. Includes a HeyMate screen-guidance prompt.

By the HeyMate project. Published 2026-11-27. Category: Workflows.

> Select the text box, open Animate in the toolbar, and choose Build In > Add an Effect > Fly In. Preview the slide and use Build Order to adjust when the title appears.

## Make a title fly in

Open a sample deck and type a title into a slide. Start with one text box and one effect so you can see what each setting changes.

1. Select the text box on the slide. If you are editing the text, click the text box edge so the whole object is selected.
2. Click Animate in the Keynote toolbar. In the sidebar, open Build In. This is where you choose how a selected object enters the slide.
3. Click Add an Effect and choose Fly In. Preview the effect and adjust its duration or direction if those options are available.
4. Play the slide and check that the title lands where you expect. If the title waits for a click, open Build Order to check its start setting.

The HeyMate launch film shows this exercise on a sample slide titled “Our Trip to the Moon.” The cuts show the Animate button, effect list, and finished title animation. [Watch the Keynote sequence in the launch film](https://sayheymate.com/blog/meet-heymate#film)

## Choose when the title appears

Click Build Order at the bottom of the Animate sidebar. Select the title’s build and check its Start setting. Use On Click when you want to cue the title yourself. If there is another build, With Build can start them together and After Build can start the title when the previous build finishes. Preview the slide to see how the effects play together. [Apple’s guide to build timing](https://support.apple.com/en-kw/guide/keynote/tan3ad5f8d82/mac)

Use Build In for an entrance, Build Out for an exit, and Action to move or change an object already on the slide. If you see transition settings instead of the object’s builds, select the title box on the slide and reopen Animate. [Apple’s guide to entrance and exit effects](https://support.apple.com/en-is/guide/keynote/tan72234bb6/mac)

## Ask for help finding the next control

Bring Keynote to the front with the text box selected. In HeyMate, hold Control + Option and ask about the step you are on. Use a sample deck while you are setting up [screen access](https://sayheymate.com/screen-guidance).

Try this prompt:

> Help me make this title fly in. Point to the next control, explain what it does, and wait while I try it.

If the sidebar looks different, describe the options you can see and ask for one corrected step. In the recorded demo, the presenter clicked each control. Once the effect works, try adding an entrance to a second text box and put it after the title in Build Order.

## Check a title animation that does not play

If nothing moves, make sure the text box has an effect under Build In and start playback from that slide. Press the advance key once to test an On Click build. If the whole slide changes instead, reselect the text box and check the effect in Build Order. That list shows which object has a build and when Keynote will play it.
