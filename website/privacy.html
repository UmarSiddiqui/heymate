Privacy

Privacy notes.

HeyMate is a Mac app. There is no HeyMate account and no HeyMate server that stores your chats. The short version, which is also written in the app: nothing runs in the background. HeyMate only takes a screenshot when you press the hotkey, and screenshots are never stored.

What HeyMate captures

  • A screenshot only when a question needs to see the screen. Text-only chat skips the capture.
  • That screenshot is temporary. It is deleted after the turn and is not written into chat history.
  • Password managers and System Settings are excluded by default.
  • You can limit capture to the frontmost window.
  • Voice in uses Apple Speech on the device unless you turn on a cloud voice.

What it stores, and where

Everything below is on your Mac, under ~/Library/Application Support/heymate/.

FileWhat it is
chats.jsonChat history. Text only. No screenshot or audio bytes.
memory.jsonThings HeyMate decided were worth remembering. You can clear it.
mates.jsonMate names, jobs, personalities, and settings.
routines.jsonSchedules for mates.
behavior-contract.mdThe rules you can edit.
skills/Your Markdown skills.
faces/Custom mate faces you imported.

API keys and connector tokens go in the macOS Keychain, not in those files. Clipboard history stays in memory and is dropped when you quit.

What leaves your Mac

  • Talk and coding-agent turns go to the CLI you already use — Claude Code, Codex, or OpenCode — or to a Custom API endpoint you configure yourself. HeyMate does not add its own bill.
  • Cloud speech (optional) only if you enable it.
  • Composio and other connectors only call the apps you connect, and anything that sends, deletes, or pays asks first.
  • Analytics ships only in a build that was compiled with an analytics key. This website has none.

How to delete everything

In the app, clear memory from the Memory section. To remove the local files entirely, quit HeyMate and delete ~/Library/Application Support/heymate/. Keychain items named for HeyMate can be removed in Keychain Access.
