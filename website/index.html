What’s new.

The latest improvements to your little desktop crew.

  1. 1.0.76Oct 28, 2026
    • Help that points and draws. Your mate can draw circles, arrows, and cards in time with spoken explanations, with smoother cursor pointing and movement.
    • Your browser, already signed in. Agents can work in your signed-in Chrome, with their tabs kept together in a HeyMate tab group.
    • Follow the work. Floating job bubbles show what a task is doing and let you reply in place. Full release notes.
  2. 1.0.75Oct 27, 2026
    • The agent sees what you mean. Your screen selection, saved memories for the mate you’re talking to, the current walkthrough step and attached images now reach the agent every turn.
    • Chat summaries keep up. Each mate’s running summary of recent chats updates again after every reply.
    • No false failures. If your Mac’s voice can’t play a reply, the answer stays in the chat without a “could not finish” error under it.
  3. 1.0.74Oct 27, 2026
    • HeyMate’s own agent. The agent now runs on HeyMate’s built-in Pi harness. Pick a subscription or API key, model and effort in Brain, or change them right from the chat.
    • Add to a running task. Send a follow-up, an image or a screen while the agent works, and it joins the task instead of restarting it. Long tasks are told to wrap up before they run out of time.
    • Safer actions. HeyMate keeps a record of every action it has taken in a chat, so a retry never sends twice, even after a long chat is summarized. Questions from the agent can offer suggested answers.
    • A seamless notch. The notch gradient now flows across the whole workspace and the active chat’s neck.
