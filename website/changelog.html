Changelog

What's new.

Every HeyMate release, newest first. HeyMate checks for new releases on its own. Commit-level notes are on GitHub Releases.

Website & contributor update

October 11, 2026 · This update changes the website and project documentation, not the downloaded app.

  • A clearer starting point. The homepage now leads with step-by-step guidance for desktop apps and websites, with macOS shown as the current platform.
  • More precise information. Privacy, provider limits, and installation notes explain what is captured, what can run in the background, and the current signing limitations. The tour is labeled as recreated UI, and the download count includes DMG files only.
  • Easier to contribute. A contribution guide includes build instructions, a code map, and three small starter tasks. The existing MIT license is now available at the repository root.

    • Follow the work. Floating job bubbles show what a task is doing and let you reply in place. Full release notes.

    • No false failures. If your Mac’s voice can’t play a reply, the answer stays in the chat without a “could not finish” error under it.
