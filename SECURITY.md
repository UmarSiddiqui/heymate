# Security

HeyMate runs on your Mac with Screen Recording, Accessibility and Microphone
access, and updates itself from GitHub Releases. Security reports matter.

## Reporting a vulnerability

Please report privately, not in a public issue:

- **GitHub:** use [Report a vulnerability](https://github.com/UmarSiddiqui/heymate/security/advisories/new) on the Security tab.
- **Email:** umarsiddiqui3037+heymate@gmail.com

Include what you found, how to reproduce it, and the HeyMate version
(Settings shows it at the bottom of the sidebar). You'll get a reply within a
few days. Please give a fix time to ship before disclosing publicly.

## Supported versions

Only the latest release gets fixes. HeyMate updates itself, so most users are
on it within a day.

## Contributions

Pull requests from forks build without access to any secrets. Every release
is approved by the maintainer before it is signed and published.
