# Milo and Nova source models

Original editable Blender models for the bundled HeyMate characters. Classic and Future outfits are preserved separately; the Milo accessories scene includes accessory geometry. Rendered runtime artwork lives in `heymate/HeyMate/Assets.xcassets`; appearance and gaze composition live in `MiloCharacter.swift` and `MiloGazeArtwork.swift`.

These are the character sources recovered from the October 15 character session, not screen captures or packaged app builds. Open the `.blend` files in Blender to edit the source geometry and materials.
